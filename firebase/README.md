# Firebase — Nosso Canto

Esta pasta será usada para manter uma cópia **versionada** das regras do Firestore do projeto Nosso Canto.

- `firestore.rules`: será criado depois que as regras atuais forem fornecidas e revisadas.
- As regras aqui são **cópia de referência**. Editar um arquivo no GitHub **não publica** regras no Firebase automaticamente.
- Nunca guardar aqui senhas, PINs, tokens, chaves privadas, credenciais de conta de serviço nem chaves secretas de API.
- O repositório é público; considere qualquer informação aqui publicamente visível.
- Ao revisar regras, preservar proteção das coleções de postagens, comentários, chat privado e `ben_estado`, que contém os cuidados compartilhados do Ben.
